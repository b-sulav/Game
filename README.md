# ASTRO-DODGE
**Dodge the asteroids and survive!**

Astro-Dodge is a fast-paced survival game that tests your quick reactions and strategic thinking. Pilot an advanced, nimble spacecraft through an infinite asteroid field, aiming to stay alive as long as possible to accumulate high scores.

---

## 🚀 Quick Start
1.  **Install Processing IDE**: Download and install the Processing IDE on your device.
2.  **Download Files**: Ensure you have the `main` folder containing all `.pde` files (like `spaceship.pde`, `asteroids.pde`, etc.) and the `data` folder.
3.  **Add Sound Library**: 
    * In Processing, go to **Sketch** > **Import Library** > **Manage Libraries**.
    * Search for **"Sound"** and install the version by **The Processing Foundation**.
4.  **Run**: Open `main.pde` and press **Ctrl+R** (Windows) or **Cmd+R** (Mac).

---

## 🎮 Controls & Power-ups
| Action | Control | Description |
| :--- | :--- | :--- |
| **Movement** | **Mouse** | Move left/right to steer. Features dynamic tilting based on speed. |
| **Laser** | **Hold A** | Fires a vertical beam to destroy asteroids (0.8s use, 3s recharge). |
| **Shield** | **Hold S** | Deploys a round shield that destroys asteroids on contact (1s use, 3s recharge). |
| **Slow Time**| **Hold D** | Drastically decreases asteroid speed (0.8s use, 3s recharge). |
| **Pause** | **P** | Pauses or unpauses the game. |
| **Mute** | **M** | Toggles game music. |

## 🛠 System Requirements
* **OS**: Windows 7/8/10, macOS 10.13+, or Linux (Ubuntu 20.04+).
* **Processor**: Intel Core i3 or equivalent (Dual-core 2.0GHz).
* **Memory**: 2 GB RAM.
* **Graphics**: Integrated graphics with OpenGL 2.1 or higher support.
* **Resolution**: $1920\times1080$.
